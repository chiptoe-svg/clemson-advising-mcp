HON 2070 - Reasoning, Critical Thinking, and Problem Solving
3 Credits (3 Contact Hours)
Interdisciplinary honors seminar that teaches a particular set of tools for thinking and analysis, showing how these tools can be applied to different kinds of problems in different disciplines. May be repeated for a maximum 12 credits, but only if different topics are covered. Preq: Membership in the Clemson University Honors College.
