IE 4670 - Systems Design II
4 Credits (2 Contact Hours)
Provides students with the challenge of integrating and synthesizing general engineering knowledge into creatively solving real-world, open-ended problems. This includes developing the problem statement, objectives, and criteria; data collection; technical analysis; developing and integrating recommendations; and presenting results. Preq: All of the following Industrial Engineering courses: IE 2100, IE 3010, IE 3600, IE 3610, IE 3800, IE 3810, IE 3840, IE 3860, IE 4400, IE 4610, IE 4820, and IE 4880. Coreq: IE 4671.
